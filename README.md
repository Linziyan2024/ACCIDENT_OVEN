# ACCDENT OVEN Bagel Shop

Static bilingual bagel shopping site for ACCDENT OVEN.

## Files

- `index.html` - single-page storefront, menu, shop, cart, FAQ, account modal, and search.
- `styles.css` - responsive storefront design and product card styles.
- `app.js` - bilingual content, product data, cart behavior, FAQ toggles, search, and generated bagel visuals.
- `assets/` - user-provided logo and bagel reference photo used by the site.

## Pricing

Product prices are placeholders in `app.js`. Search for `TODO: Price placeholder` and change the numeric `price` values when final prices are ready.

## Local Preview

Open `index.html` directly in a browser, or serve this folder with any static file server.
